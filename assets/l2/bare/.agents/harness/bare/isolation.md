## 『제어 문맥 격리』

### 명령
```bash
tmux -L <전용 소켓 이름> new-session -d -s <세션명>   # 소켓을 갈라 다른 작업과 섞이지 않게 한다
tmux -L <전용 소켓 이름> list-panes -a
```

### 보장 수준
**관측.** Run·mailbox 라는 제어 문맥 자체가 없으므로 격리할 상태도 없다. 대신 **소켓(`-L`)과 세션 이름으로
물리적으로 가른다** — 다른 작업의 pane 을 밟지 않는 것이 여기서 할 수 있는 전부다.

### 상황 → 행동
- **차단 화면**: 해당 없음 — 소켓을 갈라 새 세션을 만드는 것뿐이라 에이전트 화면을 지나지 않는다.
- **타임아웃·빈 결과**: 기다릴 제어 문맥이 없다. **빈 결과라는 개념도 없다** — 격리는 소켓 이름·세션 이름으로만 하고, 그 이름을 잘못 쓰면 조용히 남의 서버에 붙는다(그것이 이 도구의 위험이다).
- **부분 실패**: 기본 소켓(`default`)을 쓰면 사용자의 다른 tmux 작업과 같은 서버에 들어간다 — 작업 전용
  소켓 이름을 쓰고 그 이름을 작업 폴더에 적는다.
- **복구**: 섞였으면 새 소켓으로 옮기고, 남은 pane 은 사람이 센다.
- **하지 말 우회**: 사용자의 기본 서버에서 세션·pane 을 지우지 않는다.
