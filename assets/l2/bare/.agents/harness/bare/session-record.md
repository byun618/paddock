## 『세션 기록 오라클』

### 명령

이 도구에서는 이것이 **유일한 사후 확인 수단**이다. 그리고 **경로를 얻는 수단이 없다** —
tmux·iTerm2 는 JSON 응답을 돌려주지 않으므로 기록 경로를 응답에서 꺼낼 수 없다.
그래서 경로는 **사람이 기동 때 스스로 정해 두는 것**이 유일한 방법이다:

1. **기동할 때 세션 id 를 직접 박는다** — 예: `claude --session-id <내가 만든 UUID>`.
   그러면 H6 의 홈 경로 + 그 UUID 로 파일이 특정된다. **이것이 유일하게 증명에 가까운 경로다**
   (id 를 박지 않으면 provider 가 스스로 만들고, 그 값을 돌려받을 창구가 없다).
2. 박지 않았다면 H6 의 홈 경로에서 **cwd·시각으로 후보를 좁힌다.** 동시에 여러 세션을 띄웠으면
   **어느 파일이 그 pane 의 것인지 가릴 수 없다 — 공백이다.** 추측한 파일을 근거로 쓰지 않는다.
3. 기동 명령·시각·고른 파일 경로를 **작업 폴더에 적어 둔다.** 이 도구에서는 그 기록이 유일한 연결 고리다.

읽는 방법(`jq` 블록)은 [contract.md](../contract.md) H6 에 있다 — 거기서 고른 파일 경로를 인자로 준다.

### 보장 수준
**관측.** 그리고 이 도구에서는 **배달의 유일한 사후 단서**다. 기록에 본문이 있으면 "들어갔다" 를 관측한 것이고,
없으면 배달 실패인지 기록 생략인지 가를 수 없다(H1). **사람이 붙여 넣은 경우에도 같은 모양으로 남는다** —
그래서 사람 개입 구분에는 쓸 수 없다.

### 상황 → 행동
- **차단 화면**: 해당 없음 — 기록 파일을 읽는 것뿐이라 화면을 거치지 않는다.
- **타임아웃·빈 결과**: 기록 부재는 배달 실패의 증거가 아니다.
- **부분 실패**: 같은 폴더에 세션이 여럿이면 어느 것이 이 pane 인지 가릴 수 없다 — 기동 시각으로 좁히고
  좁힌 근거를 적는다.
- **복구**: 없다. 확인 불가는 확인 불가로 적는다.
- **하지 말 우회**: 기록에 본문이 1건 있는 것을 "정확히 한 번 배달됨" 으로 승격하지 않는다 — 기록은 계약이 아니다.
