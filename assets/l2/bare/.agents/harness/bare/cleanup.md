## 『회수·정리』

### 명령
```bash
tmux list-panes -a -F '#{pane_id} #{pane_pid} #{session_name} #{pane_current_command}'
tmux kill-pane -t <대상>        # 사람이 소유를 확인한 뒤에만
tmux kill-session -t <세션명>
# iTerm2 — 사람이 탭을 닫는다
```

### 보장 수준
**관측(tmux, 조건부) / 공백(iTerm2).** tmux `%N` 은 한 서버 수명 안에서 재사용되지 않으므로 **같은 서버 안에서는**
`(pane_id, pane_pid)` 쌍이 맞으면 같은 pane 이라고 관측할 수 있다. 서버가 재시작했거나 `respawn-pane` 이 있었으면
그 관측은 깨진다. iTerm2 는 세대 개념이 없다.

### 상황 → 행동
- **차단 화면**: 해당 없음 — 목록·종료 명령은 pane 에 입력을 넣지 않는다(차단은 『화면 관측』이 본다).
- **타임아웃·빈 결과**: `list-panes` 가 오류면 서버가 없는 것이다 — pane 이 모두 정리됐다는 뜻은 **아니다**
  (다른 서버·소켓이 있을 수 있다).
- **부분 실패**: **H5 — 사람이 열어 준 pane 은 남는다.** 내가 만든 pane 만 닫고, 빌린 pane 은 사람에게 알린다.
  누가 만들었는지는 도구가 기억하지 않으므로 **만들 때 작업 폴더에 적어 둔 것이 유일한 근거다.**
- **복구**: 어느 pane 을 닫아야 할지 불확실하면 **닫지 않는다.** 잘못 닫은 pane 은 되돌릴 수 없다.
- **하지 말 우회**: `kill-server`·`kill-session` 으로 통째로 정리하지 않는다 — 사용자의 다른 작업이 같은 서버에
  있을 수 있다.
