## 『준비 대기』

### 명령
```bash
tmux capture-pane -p -t <대상>            # 화면을 읽어 사람이 판단한다
# 폴링 루프를 짜도 되지만 판정 근거는 화면 문자열뿐이다
```

### 보장 수준
**공백.** "지시를 받을 수 있다" 를 돌려주는 값이 없다. 화면 문자열 일치로 짐작할 수 있을 뿐이고, 그 짐작은
**차단 화면과 준비를 가르지 못한다** — 프롬프트처럼 보이는 것이 승인 대기일 수도 있다.

### 상황 → 행동
- **차단 화면**: **사람이 읽고 사람이 치운다.** 이 도구에서는 예외 없이 그렇다.
- **타임아웃·빈 결과**: 화면이 안 바뀌는 것은 준비의 증거도 차단의 증거도 아니다.
- **부분 실패**: 해당 없음 — 대기가 사람의 판단이라 되돌릴 중간 상태가 없다.
- **복구**: 사람이 본다.
- **하지 말 우회**: 화면에 프롬프트 기호가 보인다는 이유로 주입하지 않는다 — 차단 화면 위에 본문을 넣으면
  **그 화면에 대한 대답으로 먹히고 본문이 사라진다.** 이 도구의 가장 흔한 사고다.
