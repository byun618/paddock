## 『게이트 알림』

### 명령
```bash
# 코디 셸에서, 멈추기 직전에 한 번. 쓸 수 있는 쪽 하나
afplay /System/Library/Sounds/Glass.aiff     # macOS
printf '\a'                                  # 그 밖 — 터미널 벨
# 대체 경로 — 사람 또는 본체 세션이 화면을 본다
tmux capture-pane -p -t <대상>
```

### 보장 수준
**재생 요청은 관측, 들었는지는 공백이다.** 이 도구에는 알림 계약이 없고 OS 명령만 부른다. 터미널 벨은 설정에 따라 소리가 없다.
소리가 없는 환경(원격 셸·헤드리스)은 **공백**이고 판정표가 아니라 게이트 보고에 적는다 — 사람이 pane 을 본다.
멈췄는지 돌려주는 값도 없다. 화면에는 멈춘 것과 느린 것이 같은 모양으로 보인다.
OS 알림은 쓰지 않는다 — 권한이 없으면 성공 종료인 채 아무것도 뜨지 않아 실패가 가려진다.

### 상황 → 행동
- **차단 화면**: 코디가 차단 화면에 막히면 코디는 알림을 보낼 수 없다. 화면을 보는 사람만 안다.
- **타임아웃·빈 결과**: 대기 개념이 없다 — 사람이 주기적으로 본다. 화면이 그대로라는 것은 멈췄다는 근거가 아니다.
- **부분 실패**: 소리 명령이 0 이 아니면 게이트 보고 끝에 그 사실을 한 줄 적고 그대로 멈춘다. **알림 실패로 게이트 흐름을 바꾸지 않는다.**
- **복구**: 소리가 안 들리면 음량·터미널 벨 설정을 사람이 켜거나, 사람이 pane 을 지켜본다.
- **하지 말 우회**: 소리가 났다는 것을 승인이나 판정의 근거로 쓰지 않는다.
