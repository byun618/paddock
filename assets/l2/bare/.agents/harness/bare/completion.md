## 『완료 감지』

### 명령
```bash
# 없다. 이 능력은 이 도구에서 공백이다.
tmux capture-pane -p -t <대상>     # 화면 읽기 — 완료 판정 근거로 쓸 수 없다
```

### 보장 수준
**공백.** 이 매핑의 핵심 칸이다. 워커가 끝났다는 것을 돌려주는 계약이 없고, `validation.md` 가 대용으로 금지한
셋(TUI idle·파일 존재·exit 0)이 여기 있는 전부다.

### 판정표에 어떻게 나타나는가
- 워커 완료를 근거로 삼는 판정 항목의 **결과 칸 = `공백`**, 판정 칸 = `보류`(통과로 세지 않는다),
  근거 칸 = "이 도구에 『완료 감지』가 없다. 사람이 화면을 읽고 판단한 시각·화면 원자료를 남겼다".
- **원장 칸**은 그 관문을 실행하지 않았다면 `해당 없음 — 이유` 로 적는다(빈칸 금지).
- **실행 n/총 m 칸**은 사람이 화면을 본 회차를 그대로 적는다 — 한 번 보고 통과로 적고 나머지를 지우지 않는다.

### 상황 → 행동
- **차단 화면**: 워커가 차단 화면에서 멈춘 것과 일을 끝낸 것이 **화면으로는 비슷해 보인다.** 사람이 본다.
- **타임아웃·빈 결과**: 화면이 조용한 것은 끝난 증거가 아니다.
- **부분 실패**: 해당 없음 — 완료 감지 자체가 공백이라 부분 성공이라는 상태가 없다.
- **복구**: 없다 — 이것이 공백의 뜻이다. 사람이 pane 에 들어가 직접 확인한다.
- **하지 말 우회**: **파일이 생긴 것·프로세스가 끝난 것·`DONE.md` 가 있는 것을 완료로 적지 않는다.**
  다른 능력으로 이 공백을 메웠다고 적지 않는다.
